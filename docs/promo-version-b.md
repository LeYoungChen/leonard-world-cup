⚽ 世界杯快到了，我开源了一个比赛预测 Skill：**Leonard World Cup Predictor**

它不是"AI 帮你买球"，恰恰相反——它把"预测"做回它该有的样子：

🔗 每条结论都附可点击来源，不接受"据说""市场普遍认为"
📊 把赔率去水成真实隐含概率，再和模型对比
🧮 可解释的集成：实力先验 + 泊松进球模型 + 市场先验 + 情境调整
🚫 明确拒绝菠菜——只给概率、置信度和不确定性

跨 agent 可移植（Claude / Codex / 主流Agent都能用），附去水赔率脚本、JSON 输出和交付前自检清单。

MIT 开源 👉 github.com/LeYoungChen/leonard-world-cup
